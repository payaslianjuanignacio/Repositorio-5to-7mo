# Ciclo de vida

## 1. Definición

El ciclo de vida describe las etapas por las que pasa un sistema, un producto o un proceso desde que nace hasta que finaliza.

## 2. Explicación desarrollada

Todo proceso tiene una evolución. En un primer momento surge la idea o necesidad. Después se analiza, se diseña, se implementa y se evalúa. Finalmente se entrega o se mejora según los resultados.

El ciclo de vida ayuda a comprender que no existe una solución aislada, sino una secuencia ordenada de pasos.

## 3. Características principales

- Tiene etapas definidas.
- Puede ser repetitivo o mejorable.
- Permite controlar avances.
- Ayuda a planificar tareas.

## 4. Objetivos y utilidad

- Organizar proyectos.
- Evitar errores en etapas tempranas.
- Mejorar la calidad del trabajo final.

## 5. Ejemplo práctico

El desarrollo de una aplicación puede pasar por:

- idea,
- análisis,
- diseño,
- programación,
- prueba,
- entrega.

## 6. Diagrama

```mermaid
flowchart LR
    A[Idea inicial] --> B[Análisis]
    B --> C[Diseño]
    C --> D[Implementación]
    D --> E[Pruebas]
    E --> F[Entrega]
    F --> G[Mejora]
    G --> B
```

## 7. Conclusión

El ciclo de vida ayuda a entender que todo proyecto necesita planificación y revisión continua. Es una herramienta útil para ganar orden y eficiencia.
