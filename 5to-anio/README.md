## Objetivo general

Desarrollar una mirada sistemática de la realidad, entender la representación gráfica de procesos y aprender a describir situaciones con modelos simples y claros.

## Cómo estudiar este bloque

1. Leé la definición del tema.
2. Revisá la explicación desarrollada.
3. Identificá sus características.
4. Analizá el ejemplo práctico.
5. Mirá el diagrama asociado.
6. Cerrá con la conclusión resumida.
