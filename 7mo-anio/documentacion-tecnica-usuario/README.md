# Documentación técnica y de usuario

## 1. Definición

La documentación técnica y la documentación de usuario son dos formas de explicar un sistema, pero están dirigidas a públicos diferentes y tienen objetivos distintos.

## 2. Documentación técnica

Está dirigida principalmente a programadores, desarrolladores y personal técnico. Describe cómo está construido el sistema y cómo funciona internamente.

Puede incluir:

- estructura del proyecto y organización de archivos;
- tecnologías, lenguajes y herramientas utilizadas;
- diseño de la base de datos;
- clases, módulos y funciones principales;
- requisitos técnicos y procedimientos de mantenimiento.

## 3. Documentación de usuario

Está dirigida a las personas que utilizan el sistema. Explica cómo realizar las tareas disponibles sin necesidad de conocer el código.

Puede incluir:

- requisitos para utilizar el programa;
- pasos para iniciar sesión;
- explicación de las funciones y pantallas;
- instrucciones para realizar operaciones;
- soluciones a problemas frecuentes.

## 4. Tareas y procesos

Describen las actividades que realiza el sistema y el orden en que se ejecutan. Pueden documentarse mediante explicaciones, listas de pasos o diagramas.

## 5. Manual de usuario

Es un documento que reúne instrucciones para utilizar correctamente un programa. Conviene organizarlo por funciones, utilizar un lenguaje claro e incluir imágenes cuando ayuden a comprender los pasos.

## 6. Ejemplo

En una aplicación escolar, la documentación técnica puede explicar cómo se conecta el programa con la base de datos. El manual de usuario puede indicar cómo registrar un alumno, buscarlo o modificar sus datos.

## Para recordar

La documentación técnica explica cómo está construido el sistema; la de usuario explica cómo utilizarlo.
