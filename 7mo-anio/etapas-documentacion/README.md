# Documentación de relevamiento, diseño, técnica, usuario, instalación y despliegue

## 1. Definición

Durante el desarrollo de un sistema se elaboran distintos documentos. Cada uno registra información de una etapa o ayuda a un grupo de personas a comprender una parte del proyecto.

## 2. Tipos de documentación

- **Relevamiento:** registra las necesidades, problemas y requisitos planteados por el cliente o los usuarios.
- **Diseño:** muestra cómo estará organizado el sistema, por ejemplo mediante diagramas, estructura de datos y diseño de pantallas.
- **Técnica:** explica la programación, la arquitectura, las herramientas y la estructura interna.
- **De usuario:** enseña a utilizar las funciones del sistema mediante instrucciones claras.
- **Instalación:** explica los requisitos y pasos necesarios para instalar el programa.
- **Despliegue:** describe cómo publicar o poner el sistema en funcionamiento para que los usuarios puedan acceder a él.
- **Control de versiones:** registra los cambios y permite identificar las distintas versiones del proyecto.

## 3. Diferencia entre instalación y despliegue

La instalación se centra en preparar el programa en un equipo o entorno. El despliegue comprende el proceso de poner una versión del sistema a disposición de sus usuarios en el entorno donde funcionará.

## 4. Ejemplo práctico

En una aplicación de ventas, el relevamiento reúne las necesidades del comercio; el diseño muestra las pantallas y las tablas; la documentación técnica explica el código; el manual enseña a registrar ventas; y los documentos de instalación y despliegue indican cómo preparar y publicar la aplicación.

## 5. Para recordar

Cada documento responde a una necesidad diferente: conocer el problema, diseñar la solución, construirla, utilizarla y ponerla en funcionamiento.
