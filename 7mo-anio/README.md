## Cómo recorrer el material

1. Abrí el tema desde el índice.
2. Leé la definición y los conceptos principales.
3. Revisá el ejemplo, el código o el diagrama.
4. Intentá explicar con tus palabras para qué sirve y cuándo se utiliza.
5. Consultá los enlaces de “Temas relacionados” para conectar los contenidos.

## Objetivo general

Comprender cómo se analizan, diseñan, programan, documentan y planifican sistemas informáticos, relacionando los conceptos con ejemplos prácticos.
