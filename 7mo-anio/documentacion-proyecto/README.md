# Documentación de un proyecto: 7 pasos

## 1. Definición

Documentar un proyecto consiste en registrar información sobre sus etapas, decisiones y resultados. Esto permite comprender cómo se desarrolló, cómo funciona y cómo puede mantenerse.

## 2. Los siete pasos

1. **Relevamiento:** recopilar información y conocer las necesidades del cliente o usuario.
2. **Análisis:** estudiar los requisitos y definir qué debe hacer el sistema.
3. **Diseño:** organizar la estructura, los datos, los diagramas y el funcionamiento.
4. **Documentación técnica:** explicar cómo está construido el sistema y qué tecnologías utiliza.
5. **Documentación de usuario:** explicar cómo utilizar el programa y sus funciones.
6. **Instalación y despliegue:** registrar cómo instalar el sistema y ponerlo en funcionamiento para sus usuarios.
7. **Control de versiones:** registrar los cambios realizados y conservar el historial de versiones del proyecto.

> Nota: la guía enumera estos contenidos como siete pasos. El control de versiones puede acompañar todo el desarrollo, no necesariamente realizarse solo al final.

## 3. Ejemplo práctico

Para crear un sistema de inscripción escolar, primero se consulta qué necesita la institución (relevamiento). Después se definen las funciones (análisis), se diseña la base de datos y las pantallas (diseño), se documenta su construcción y uso, se instala y se registran las modificaciones mediante control de versiones.

## 4. Importancia

La documentación permite mantener un registro del trabajo, facilitar la comunicación del equipo y ayudar a quienes deban utilizar o modificar el sistema en el futuro.

## Para recordar

Los pasos ordenan la información del proyecto desde el conocimiento de la necesidad hasta su puesta en funcionamiento y el registro de cambios.
